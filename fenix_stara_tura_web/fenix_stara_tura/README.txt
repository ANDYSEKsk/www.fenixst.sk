FÉNIX STARÁ TURÁ – PHP WEB

Obsah:
- index.php – všetky podstránky a obsah
- assets/css/style.css – dizajn a responzivita
- assets/js/main.js – mobilné menu

SPUSTENIE LOKÁLNE:
1. Nainštaluj si PHP (alebo XAMPP).
2. Skopíruj priečinok fenix_stara_tura do htdocs (pri XAMPP).
3. Spusti Apache.
4. Otvor http://localhost/fenix_stara_tura/

NASADENIE NA HOSTING:
1. Nahraj celý obsah priečinka na hosting do webového priečinka (často public_html alebo www).
2. Hosting musí podporovať PHP 8.0 alebo novšie.
3. Skontroluj, či sa načítava index.php.

KONTAKTNÝ FORMULÁR:
Formulár používa PHP mail(). Nie každý hosting má odosielanie mail() povolené.
Ak odosielanie nefunguje, treba nastaviť SMTP cez hosting alebo doplniť SMTP knižnicu.
Cieľová adresa je staratura@do-fenix.sk.
